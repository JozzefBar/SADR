# SADR

R scripts from seminars (`seminar/`) and assignments (`tasks/`).

HTML reports are not stored in the repository. Generate them from the `.R` files.

## How to get the HTML report

The easiest way is RStudio:

1. Install [R](https://cran.r-project.org/) and
   [RStudio Desktop](https://posit.co/downloads/).
2. Download this repository and open an `.R` file in RStudio.
3. If RStudio shows a banner about missing packages, click **Install**.
4. Click **File → Compile Report...**, choose **HTML** and click **Compile**.

RStudio creates the HTML file next to the `.R` file and opens it.
